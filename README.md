# Shūri

A beautifully minimal, functional task management web application focused on core features and Japanese minimalism. Clarity in Motion.

## Features
- **Task Management**: Create, edit, complete, and delete tasks.
- **Real-time Filters**:
  - **All**: All active tasks.
  - **Overdue**: Tasks with a past deadline.
  - **Due Today**: Tasks due within 24 hours.
  - **Due Soon**: Tasks due beyond 24 hours.
  - **Completed**: All finished tasks.
- **Live Timer**: Real-time countdown for tasks with a set duration.
- **Local Persistence**: Tasks are saved automatically to `localStorage`.

## Tech Stack
- **Frontend**: React (Vite + TypeScript)
- **Styling**: CSS Modules
- **Icons**: Lucide React
